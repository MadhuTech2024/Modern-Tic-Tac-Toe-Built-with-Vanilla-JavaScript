# Modern Tic Tac Toe 🎮

A sleek, modern redesign of the classic Tic-Tac-Toe web game featuring a dark glassmorphism aesthetic, responsive CSS Grid layout, dynamic neon animations, and robust vanilla JavaScript state logic.

---

## 🌟 Features

* **Glassmorphism UI:** Modern frosted-glass aesthetics with layered radial gradients and glowing neon accents.
* **Turn Indicator:** Dynamic header badge showing which player's turn is active (Cyan for **Player X**, Rose for **Player O**).
* **Game State Management:** Accurately detects all 8 possible win patterns or draw situations.
* **Winner Modal:** A celebratory pop-up overlay announcing the victor with a quick "Play Again" reset option.
* **Pure Vanilla Stack:** Zero external libraries or frameworks—built completely with HTML5, modern CSS3, and ES6 JavaScript.
* **Fully Responsive:** Adapts cleanly to mobile, tablet, and desktop viewports using CSS Grid and `min()` units.

---

## 🛠️ Built With

* **HTML5:** Semantic markup and accessibility attributes.
* **CSS3:** CSS Grid, CSS Variables, glassmorphism (`backdrop-filter`), flexbox, and keyframe-inspired hover transitions.
* **JavaScript (ES6):** Modular event handling, DOM manipulation, and array-based pattern checking algorithms.
* **Google Fonts:** Styled using the modern geometric typeface **Outfit**.
